# 关于“复古未来式”适老智能家居项目的构想与原型


## 动机与概念

此项目源自我对老年人、尤其是难以适应现代科技产品的老年人的生活的观察与思考。
我希望人在暮年，失去健康的身体甚至是一部分记忆的情况下也可以活得体面。这一点与追逐经济趋势无关，这是我最初、最根本的动机。
因此，需要设计一套适老化的智能家居系统。它必须是：

### 1.软件层面：学习成本极低，符合本能直觉的

我的奶奶学不会使用任何智能设备，只使用座机电话、收音机与电视来获取外界信息，还有洗衣机、冰箱等家电。我的最终目标是让我奶奶这样的老人也能自如使用这套系统。
所以我会采用“复古未来”的设计哲学，最大化地减少冗余的“科技”元素，用拟物、直观的形式让使用者理解。
初代iPhone是个成功的例子。一个从未接触过智能设备的5岁孩子能在几分钟内学会操作初代iPhone。这得益于它拟物化的ui设计（如设置图标是一堆金属齿轮、电话就是一个听筒）和符合直觉的交互设计。我的系统需要延续这一点。

### 2.硬件层面：鲁棒（耐用）性极强，不依赖云端、可离线稳定运行，模块化的

我认为技术应该服务人，而不是奴役人。迫使用户频繁更新设备、购买云端服务、只能使用某一家的产品，诸如这样的硬件设备（或者商业策略）是极其不人道的。
好的设备应该像我奶奶的收音机和座机一样，默默工作，让人感受不到它的存在，同时又稳定可靠。我理想中的智能家居系统就像一件件家电一样，谁都可以安装，装好就可以用很多年，并且易于维修和替换。
所以它应该实现模块化，不依赖任何云端服务来执行重要决策，所有的数据都在本地。绝大多数交互使用机械结构（按钮、旋钮、灯光/声音/振动反馈），实现离线环境下的稳定运行。

### 3.原则与理念：核心开源的

如果做商业化考虑，可以为有更多需求的用户提供付费服务，但必须保证系统的核心部分开源，绝不垄断。



## 项目路线图&硬件方案

### 第一阶段 环境与感知 - 聚焦于嵌入式核心，让系统稳定扎根

主控核心 ESP32 | 环境感知 DHT11（精度太低）、BME280（计划） | 状态指示 板载LED/外接LED

### 第二阶段 交互与独立 - 突破通信与系统集成，让设备独立自主

离线通信 4G模块 | 物理交互 实体按键、旋钮编码器、蜂鸣器 | 电源管理 5V/2A独立电源模块、锂电池充放电管理

### 第三阶段 扩展与深化 - 灼眼与架构和体验，让技术真正服务于人

感知扩展 毫米波雷达、红外阵列 | 执行单元 继电器模块、智能插座 | 本地中枢 树莓派/旧手机
